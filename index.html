Informasi Sistem

Halaman web ini dikembangkan menggunakan standar HTML5 murni untuk memenuhi tugas praktikum mata kuliah Pemrograman Web di Program Studi Teknik Informatika.

Tentang Modul Praktikum

Modul ini berfokus pada pemahaman dasar struktur dokumen web, penerapan elemen semantik HTML5, pengelolaan data tabular, serta pembuatan formulir interaktif dengan validasi bawaan.

Tambah Mahasiswa Baru

Silakan lengkapi formulir di bawah ini untuk mendaftarkan data mahasiswa baru ke dalam sistem.

Formulir Data Mahasiswa



Masukkan 8 hingga 12 digit angka NPM.



Masukkan nama lengkap sesuai identitas (3-100 karakter).



Pilih program studi yang sesuai.



Rentang tahun angkatan antara 2018 sampai 2026.



Gunakan alamat email aktif yang valid.
